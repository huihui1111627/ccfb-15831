# 窑炉告警：分组、抑制与静默

一座窑出点毛病，几十座窑的探头同时刷出几百条告警，值班手机上真正要命的那条被淹没。
这个服务把告警按标签路由成组、按窗口和规则抑制、按时间段静默，只把"和上次相比变了什么"
发出去，并在多副本部署下保证一条通知只发一次（分区时宁可多发）。

告警源、通知渠道、渠道故障、副本分区全部在程序里模拟，运行可复现。

## 运行

```sh
go run ./cmd/kilnalert -check     # 跑完全部风暴并逐条核对，不启动页面
go run ./cmd/kilnalert            # 跑完后在 http://127.0.0.1:8909/ 打开页面
go run ./cmd/kilnalert -storm kiln-blackout -v   # 只跑一个风暴，打印全部差异
go test ./...                     # 单元测试 + 全部风暴的核对测试（约 3 秒）
```

## 页面

- **路由树**：每个节点的匹配条件、分组键、渠道、时间窗（是否此刻生效）、抑制规则，
  以及此刻路由到该节点的分组与组内告警。时间窗外或分支被"最深的匹配胜出"挡住的节点会显示状态。
- **当前分组**：组内标签、发往渠道、上次发送时间、还有几条在等下一次合并发送。
- **被抑制 / 被静默**：逐条列出被挡下的告警和原因——哪条静默（起止、是否已取消）
  或哪条抑制规则（源条件 → 目标条件、需相同的标签、当前命中的源告警）。
- **通知记录**：每条通知只带新增了哪几条、解除了哪几条，附送达情况、由哪个副本发出、
  重试次数、分区期间是否重复。
- **流水**：触发、解除、自动解除、静默生效/到期/取消、每次通知。

顶部可切换风暴，拖动时间轴查看任一时刻的状态；数据来自引擎每个 tick 的快照。

## 规则

**路由**（`internal/routing`）。标签匹配 `=`、`!=`、`=~`、`!~`（正则全锚定）。
自上而下，**最深的匹配胜出**；一个节点匹配后不再试兄弟节点，除非它标了"继续匹配兄弟"。
节点可带时间窗：时区、起止时刻、星期几、仅节假日；窗口可跨午夜（22:00–06:00 的凌晨属于前一天），
跨午夜、跨时区、夏令时都按各自时区的墙上时间判定。不在窗口内的节点连同子树跳过，兄弟照常尝试。

**抑制**（`internal/inhibit`）。源告警在触发时，目标和它"必须相同的标签"全部一致就不发通知；
源告警解除后目标恢复。同一 alertname 算"重新触发"要等上次解除，解除和重触发是两段 episode。

**静默**（引擎内）。按标签匹配在 `[起, 止)` 内生效，到期自动失效，可提前取消（取消在生效前则从不生效）。
**已被通知过**的告警进入静默或抑制时不会补发"解除"——它没有解除，只是不再变化。

**合并**（`internal/engine`）。每组每条渠道独立维护"接收方已知状态"：
首条通知等 `GroupWait`，之后至少间隔 `GroupInterval`；通知里 `新增 = 在发且未被挡且接收方未知`，
`解除 = 接收方已知但已不再在发（或不再路由到这）`。告警源定期重发在发的告警，超过 `StaleAfter`
没再收到即判为解除，解除也发通知。

**多副本**（`internal/channel`）。副本按顺序错开发送（渠道错峰 + 副本间隔），
看到别的副本已发就不再发；网络分区时看不到对方的知识，宁可多发。
渠道故障按指数退避重试；组切换渠道后，旧渠道上的通知作废、不再重试，新渠道从当前状态重新起一条基线。

## 核对

`internal/verify` 不调用引擎：它从**完整告警记录**（`AlertEvents`，源的所有上报）重建每个告警实例，
逐 tick 重放路由、时间窗、抑制、静默和合并规则，算出"应该发出的通知序列"，
再与实发的每一条按（组、渠道、时刻、序号）配对，并逐条比对新增/解除集合。
对账之外还检查：

- 每条通知都至少送达一次；重复只允许出现在分区期间，且必须由当时互相看不见的副本各发一次；
- 每条新增记录的告警确实在发、开始时间与观测一致；每条解除记录的告警确实已解除且带解除时间；
- 每条被抑制/被静默的说明都指向当前真正生效的静默或规则，且命中条件成立。

`-check` 输出每个风暴的应发/实发/对上条数、漏发、多发、内容不符、重复、未送达、静默与抑制计数、压缩比。

## 风暴（24 个，固定随机种子）

断电连锁、标签抖动、静默到期、静默提前取消、副本分区、跨午夜夜班、跨时区、节假日、
风机连锁、热电偶漂移、平台告警、瞬时洪峰、整片扫描、慢热、渠道切换、渠道故障重试、
断电先于高温、抑制链、夜班叠加节假日、解除与重发交错、告警源失联、全部类型混发、
洪峰中断网、已发告警进入静默。

## 目录

```
cmd/kilnalert        入口
internal/model       数据类型
internal/timewin     时间窗（跨午夜、时区、夏令时、节假日）
internal/routing     路由树
internal/inhibit     抑制规则
internal/engine      告警流水线（tick 驱动）
internal/channel     渠道、退避重试、副本与分区
internal/sim         车间场景、风暴生成、运行
internal/verify      独立重放与逐条核对
internal/report      控制台汇总
internal/web         页面与 JSON 接口
```
